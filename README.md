# app-discovery

> **Warning:** The tools in this repository are experimental and are **not** official Google products. They are intended for informational purposes and should not be used for official production workflows or certification submissions without independent verification.

## Vision

This repository provides a suite of tools to help developers and administrators discover, inventory, and validate applications and workloads running on Google Kubernetes Engine (GKE). The goal is to provide deep insights into your GKE environment, from identifying application boundaries to verifying the cluster's readiness for specialized workloads like AI/ML.

This project is part of the `gke-labs` initiative, which aims to provide tools that enhance GKE and drive the adoption of Google Cloud services.
