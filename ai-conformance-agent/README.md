# Kubernetes AI Conformance Testing Agent

> **Warning:** This is an experimental project and is **not** an official tool for Kubernetes AI conformance certification. The results generated by this agent are for informational purposes only and should not be submitted as formal conformance evidence.

## Overview

This project provides an experimental AI agent, built using the Google Agent Development Kit (ADK), designed to interact with a Kubernetes cluster to check for some of the requirements outlined in the CNCF Kubernetes AI Conformance standard.

The agent uses an LLM to interpret a list of AI conformance requirements. It then uses a `kubectl` command-line tool to inspect the cluster's configuration and reports its findings based on the command outputs.

## Project Structure

The project is organized into the following directories and files:

```
k8s-conformance-agent/
├── main.py                   # The main script to initialize and run the agent.
├── tools/
│   ├── __init__.py           # Makes the 'tools' directory a Python package.
│   └── commands.py           # Contains the `run_shell_command` tool.
└── prompts/
    └── conformance_prompt.txt  # The detailed instructions and requirements for the agent.
```

## Setup

Before running the agent, ensure your environment is set up correctly.

#### 1. Configure `kubectl`

The agent executes `kubectl` commands using the environment's current context. Make sure your `kubectl` is configured to point to the Kubernetes cluster you intend to test.

You can verify your current context by running:
```sh
kubectl config current-context
```

#### 2. Install Python Dependencies

This project requires Python 3.9+ and the Google Agent Development Kit. Install the required library using pip:

```sh
pip install google-adk
```

#### 3. Set Your API Key

This agent uses a Google Gemini model and requires a Google AI API key to function.

1.  Create an API key at [Google AI Studio](https://aistudio.google.com/app/apikey).
2.  Set the `GOOGLE_API_KEY` environment variable in your terminal.

    ```sh
    export GOOGLE_API_KEY="YOUR_API_KEY_HERE"
    ```

Now you are ready to run the agent.

## Running the Agent

To run the agent, execute the `main.py` script from the root directory of the project.

```sh
python main.py
```

The agent will start, load the instructions from `prompts/ai_conformance_prompt.txt`, and begin executing `kubectl` commands to verify the conformance requirements. You will see the agent's actions, the commands it runs, and its findings printed to the console in real-time.

## How It Works

*   **`main.py`**: This is the entry point of the application. It initializes the `Agent` with its instructions and tools, sets up the `Runner` and `SessionService`, and starts the interaction loop. It also includes a `before_tool_callback` for logging tool executions.
*   **`tools/commands.py`**: This module contains the `run_shell_command` function, which serves as the agent's tool. It allows the agent to execute any shell command, which is essential for running `kubectl`.
*   **`prompts/ai_conformance_prompt.txt`**: This text file contains the natural language instructions for the agent. It lists the specific AI conformance requirements and suggests `kubectl` commands to check for each one, guiding the agent's behavior.
